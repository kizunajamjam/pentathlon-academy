## 9. お問い合わせの受け方 🔴

現在は「フォーム / 電話 / メール / Instagram の DM」の4つを窓口として出しています。
**DM が中心** ということであれば、導線を組み直します。

フォームの内容は必ずデータベースに保存され、管理画面から確認できます。
そのうえでメール通知も設定できます（任意）。

- **9-1.** 実際に一番よく来るのはどれですか（DM / 電話 / メール）
- **9-2.** DM を一番目立つ位置に出す形にしますか
- **9-3.** フォームは残しますか
  - 残す場合: 氏名・連絡先・希望が最初にまとめて届くので、やり取りが1往復減ります
  - DM だけにする場合: 届いた内容が Instagram 側にしか残らず、あとから探しにくくなります
- **9-4.** フォームを残す場合、通知メールの宛先
- **9-5.** 誰が返信を担当しますか
- **9-6.** 「2〜3営業日以内にご返信」と書いていますが、この目安でよいですか
- **9-7.** お問い合わせ種別のプルダウンは以下6つです。過不足はありますか
  - 体験・見学のお申し込み／練習形態のご相談（個別・グループ）／入会について／料金について／取材・メディア／その他

## 公開までの流れ

1. このシートに回答をもらう
2. 文言・連絡先・スケジュールを反映する
3. 写真を差し込む
4. ドメインを取得し、Supabase と Vercel を設定して公開する
5. 最終確認 → 公開

## 特に急ぐもの

回答が来ないと他が進まないのは、この3つです。

1. **連絡先**（1章） — 全ページに出ます
2. **ドメイン**（8章） — 取得に日数がかかることがあります
3. **写真**（6章） — 撮影が必要なら最も時間がかかります
